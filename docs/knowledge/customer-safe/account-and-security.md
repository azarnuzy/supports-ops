# NusaWorkspace — Account and Security

**Visibility:** Customer-Safe  
**Policy owner:** Security and Identity  
**Effective:** 2026-09-01  
**Review cadence:** Quarterly

## Reset password

Buka halaman Login, pilih **Forgot password**, lalu masukkan email akun. Tautan reset dikirim melalui email dan kedaluwarsa setelah 30 menit. Tautan hanya dapat digunakan satu kali. Bila email belum tiba setelah lima menit, periksa spam sebelum meminta tautan baru.

Permintaan baru membuat tautan sebelumnya tidak berlaku. Support tidak dapat melihat atau menentukan password Customer.

## Akun terkunci dan email tidak dikenal

Setelah 10 percobaan login gagal dalam 15 menit, login dari alamat IP tersebut ditunda selama 30 menit. Customer dapat tetap memakai alur Forgot password. Bila sistem menyatakan email tidak dikenal, pastikan tidak ada salah ketik dan gunakan alamat yang diundang ke workspace.

Support tidak boleh mengonfirmasi apakah email milik orang lain terdaftar. Perubahan email akun harus ditangani Human Agent setelah verifikasi kepemilikan melalui email lama.

## Keamanan komunikasi

NusaWorkspace tidak pernah meminta password, one-time password, recovery code, access token, API key, atau nomor kartu penuh lewat chat maupun email. Customer yang terlanjur membagikan credential harus segera merotasinya dan menghubungi support.

Dugaan pengambilalihan akun, login asing, atau kebocoran API key selalu diteruskan ke Human Agent. AI Agent tidak menyatakan akun aman sebelum pemeriksaan selesai.

## Contoh pertanyaan retrieval

- "Berapa lama link reset password berlaku?"
- "Kenapa link reset lama tidak bisa dipakai setelah saya minta yang baru?"
- "Boleh saya kirim OTP ke support?"
- "Saya melihat login asing, apa yang harus saya lakukan?"
