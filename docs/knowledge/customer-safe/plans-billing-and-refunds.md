# NusaWorkspace — Plans, Billing, Cancellation, and Refunds

**Visibility:** Customer-Safe  
**Policy owner:** Finance Operations  
**Effective:** 2026-09-01  
**Review cadence:** Monthly

## Paket

Starter berharga USD 19 per bulan untuk satu workspace, maksimal 3 anggota, 1.000 API call per bulan, dan email support. Pro berharga USD 49 per bulan untuk satu workspace, anggota tanpa batas, 50.000 API call per bulan, API access, dan priority support.

Harga belum termasuk pajak yang diwajibkan wilayah Customer. Paket ditagih bulanan pada tanggal renewal. Upgrade berlaku segera dan selisih harga diprorata. Downgrade berlaku pada renewal berikutnya.

## Invoice dan status pembayaran

Invoice dibuat pada hari pertama setiap billing cycle dan jatuh tempo 14 hari kemudian. Invoice lama dapat dilihat melalui **Settings → Billing → Invoices**.

PAID berarti pembayaran berhasil. OVERDUE berarti pembayaran belum berhasil sampai due date. Saat OVERDUE, NusaWorkspace mencoba pembayaran kembali selama masa tenggang tujuh hari. Customer harus memperbarui metode pembayaran di **Settings → Billing → Payment method**. Support tidak menerima nomor kartu melalui chat.

Status paket dan invoice Customer adalah data live dan hanya boleh dijawab berdasarkan Business Tool. Jika Tool tidak tersedia, jangan menyimpulkan status dari dokumen ini.

## Pembatalan

Admin workspace dapat membatalkan paket melalui **Settings → Billing → Cancel subscription**. Akses tetap aktif sampai akhir periode yang sudah dibayar. Tidak ada biaya baru setelah periode itu berakhir. Pembatalan tidak menghasilkan refund prorata otomatis.

Pemulihan pembatalan sebelum akhir periode harus ditangani Human Agent. AI Agent tidak dapat membatalkan atau memulihkan langganan.

## Refund

Refund dapat dipertimbangkan untuk tagihan pertama bila permintaan diajukan dalam 14 hari setelah charge dan penggunaan tidak melebihi 100 API call serta dua anggota aktif. Tagihan renewal, refund prorata, dan permintaan di luar 14 hari ditinjau kasus per kasus.

AI Agent tidak boleh menjanjikan, menyetujui, atau memproses refund. Setiap permintaan refund dan sengketa pembayaran harus dieskalasi ke Human Agent.
