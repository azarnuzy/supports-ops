# Setting up two-factor authentication (2FA)

**Visibility: Customer-Safe**

Two-factor authentication adds a one-time code from an authenticator app on top of your password. We support any TOTP app — Google Authenticator, Authy, 1Password, and similar.

To turn it on, go to **Profile → Security** and select **Enable 2FA**. Scan the QR code with your authenticator app, then enter the six-digit code it generates to confirm setup. You will also receive ten backup codes — store them somewhere safe, since each one can be used only once if you lose access to your authenticator app.

If you lose both your authenticator app and your backup codes, we cannot re-enable your account access from chat. A Human Agent will ask you to verify your identity through the email on file before manually disabling 2FA on your account.

2FA is optional but recommended for any account with Admin access, since Admins can manage billing and export Workspace data.
