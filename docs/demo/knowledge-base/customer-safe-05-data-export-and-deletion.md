# Exporting or deleting your Workspace data

**Visibility: Customer-Safe**

Admins can export a full copy of Workspace data — tickets, messages, and knowledge sources — as a JSON archive from **Settings → Billing → Data export**. Exports are generated asynchronously and emailed as a download link to the requesting Admin within 24 hours; the link expires after 7 days.

Deleting a Workspace is permanent and cannot be undone from the product itself. To delete a Workspace, an Admin must contact support directly; we require this to be handled by a Human Agent rather than self-service, since it also cancels any active subscription and cannot be reversed once processed.

We retain deleted Workspace data for 30 days after processing in case of accidental deletion requests, then permanently remove it. If you delete a Workspace by mistake, contact support within that window.
