# 11 — Presentation Blueprint

Baca dan ikuti `docs/presentation-analysis/00-analysis-contract.md`, terutama bagian **Aturan Bahasa**. Judul, isi slide, dan talking points harus terdengar natural ketika dibacakan.

Baca seluruh analysis dossier yang sudah diverifikasi di:

`docs/presentation-analysis/`

Sekarang buat **PRESENTATION BLUEPRINT SupportOps** untuk durasi 15–20 menit.

Ini belum membuat file PPT.

Tentukan minimum slide yang diperlukan.

Presentation narrative utama dapat mengikuti:

Problem  
→ Product  
→ Configured Workspace / Demo Setup  
→ Demo  
→ System Architecture  
→ Message Processing  
→ AI Agent  
→ Observability  
→ Evaluation  
→ Cost  
→ Closing

Tetapi urutan dapat diubah jika hasil narrative analysis merekomendasikan sesuatu yang lebih baik.

## Konteks Demo

Demo menggunakan satu workspace yang sudah dikonfigurasi dengan:

- MCP Shopify
- Tools
- AI Instructions
- Evaluation
- User
- WhatsApp configuration
- serta konfigurasi workspace lain yang relevan

Jangan mengalokasikan waktu panjang untuk setup.

Jika workspace configuration perlu dijelaskan, gunakan hanya sebagai bridge untuk menunjukkan bahwa behavior AI dibentuk oleh configuration yang nyata.

Untuk setiap slide tentukan:

- Slide purpose
- Audience question
- One key takeaway
- Content
- Supporting evidence
- Visual asset
- Demo relation jika ada
- Speaker talking points
- Estimated duration
- Transition ke slide berikutnya

Gunakan category:

- BUSINESS
- PRODUCT
- DEMO
- ARCHITECTURE
- AI
- RELIABILITY
- ECONOMICS

Jangan membuat long bullet list.

Gunakan prinsip:

> ONE SLIDE = ONE IDEA

Jika informasi terlalu detail untuk main presentation, pindahkan ke:

**BACKUP SLIDES**

Pastikan total durasi berada di kisaran 15–20 menit.

Selain slide structure, hasilkan juga:

1. Demo insertion point
2. Demo preparation summary
3. Asset mapping
4. Speaker-time allocation
5. Backup slide candidates
6. Risiko utama presentasi
7. Fallback jika live demo gagal

Simpan ke:

`docs/presentation-analysis/11-presentation-blueprint.md`
